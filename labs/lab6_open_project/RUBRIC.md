# Lab 6 assessment rubric (100 points)

| Criterion | Points | Evidence expected |
|---|---:|---|
| Problem + measurement contract | 15 | task, prediction unit, PCAP provenance, label semantics, leakage exclusions, split unit |
| Preprocessing/aggregation rationale | 10 | flow/session/burst definitions and consequences of changing them |
| Representation design | 20 | explicit preserved/lost information, budgets, truncation/normalization, semantic rationale |
| Closest prior art + claim discipline | 10 | closest representation, retained/changed elements, bounded novelty claim |
| Matched-information baselines | 15 | same raw observables where comparison claims representation benefit |
| Ablations + falsification tests | 15 | controls capable of disproving the proposed explanation |
| Reproducibility + implementation | 10 | runnable code, metadata, seeds, split policy, environment, result artifacts |
| Limitations + failure analysis | 5 | negative cases, unsupported generalizations, deployment/measurement boundary |

A graph is not awarded points merely for being a graph. N1-N7 is a profile, not a score. A non-graph solution can receive full credit.
