# Course Repository Model

All Labs in this Course repository are available from the beginning so you can see the semester's complete path. Work through them in the order specified by the course.

Canonical reference solutions are **not** stored here. As the class moves to the next Lab, the previous Lab's reference solution may be published in the separate Solutions repository.

Use Git locally to track your work. The core workflow is:

```bash
git status
git diff
git add -A
git commit -m "Describe your work"
git log --oneline --decorate -5
```

A personal GitHub repository is not required unless the instructor explicitly asks for one.
